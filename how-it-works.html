How It Works

The system uses predefined classification rules to identify selected polymers from their basic characteristics.

1

Select

Select the source, polymer type and polymerization type from the available options.

2

Analyze

The system compares the selected characteristics with predefined classification rules.

3

Identify

The system displays the corresponding polymer, along with its properties and applications.

4

Learn

View the identified polymer's properties, structure and common applications.
