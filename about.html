About the Project

The Smart Polymer Identification System is a simple web-based educational application developed for Engineering Chemistry.

The system identifies selected polymers based on their basic characteristics using predefined classification rules.

Project Objectives

  • To understand the classification of polymers.
  • To identify selected polymers using their basic characteristics.
  • To connect Engineering Chemistry concepts with basic computer programming.
  • To develop a simple and user-friendly web application.

Polymers Covered

Polyethylene, Nylon 6,6 and Epoxy Resin.

Technology Used

HTML, CSS and JavaScript.

Project Workflow

  1. User selects the polymer characteristics.
  2. The JavaScript program compares the selections with predefined rules.
  3. The system identifies the matching polymer.
  4. The result displays the polymer's properties and applications.

Project Scope

This application is designed as an educational demonstration of polymer classification. It is limited to the selected polymers included in this project and is not intended to be a universal polymer identification instrument.

Disclaimer

This system is intended only for educational and conceptual demonstration. The identification is based on predefined characteristics and should not be used as a substitute for laboratory testing or professional material analysis.
